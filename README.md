# PlaneRNG Roblox Companion Script

PlaneRNG Companion Hub is a client-side Roblox script with a simple in-game panel for personal camera and interface preferences. This PlaneRNG Roblox script adds camera field-of-view presets, a resizable panel, and a keyboard shortcut to show or hide the panel; it does not automate gameplay or modify game data.

## Install

1. Open a Roblox experience you own or are authorized to edit in Roblox Studio.
2. In Explorer, navigate to StarterPlayer > StarterPlayerScripts.
3. Create a LocalScript and paste in the contents of `PlaneRNGCompanion.client.lua`.
4. Start a play test. The companion panel appears on the left side of the screen.

## Use

- Select a camera view button to set the field of view to 70°, 85°, or 55°.
- Select the UI size button to cycle through 100%, 115%, and 90%.
- Select Hide companion to hide the panel. Press Right Shift to show or hide it.
- After the character respawns, the script sets the local camera field of view to 70°.

The camera setting may be changed by the experience. Use this script only in experiences you own or are authorized to edit.
